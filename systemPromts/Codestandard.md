# CODESTANDARD.md

## Core principles

- Write clear and readable code.
- Prefer simple solutions over unnecessary complexity.
- Avoid duplicated logic, where reasonable.
- Do not leave unused code variables, imports or commented-out code.

## Formatting

- use section divider in between methods: “//--------------------------------------------------------------”
- Keep formatting consistent with the surrounding code. 
- Do not mix tabs and spaces. 

## Naming conventions

- Classes: `PascalCase`.
- Methods: `camelCase`.
- Variables: `camelCase`.
- directories `lowercase`.
